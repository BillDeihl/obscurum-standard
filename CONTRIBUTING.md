# Contributing to OBSCURUM (public paper)

Thank you for helping improve the standard. This repository is **paper-only**.

## Ways to contribute

1. **Open an issue** for gaps, ambiguities, scope disputes, or proposed section changes.  
2. **Open a pull request** for concrete wording edits once the direction is clear.  
3. **Cite sources** when you claim prior art, measurement methods, or OWASP mappings.

## Rules

- Change the **standard text and supporting docs**, not tooling. Scorers and labs belong in separate repos when published.  
- Stay **vendor-neutral**. Do not turn the standard into a product pitch.  
- Stay inside **static / at-rest** scope unless a change explicitly revises Scope and Non-Goals.  
- Do not add acquisition, exploitation, or “how to bypass” playbooks.  
- Prefer primary or authoritative sources (OWASP MAS/MASTG, peer-reviewed work, standards bodies) over marketing blogs.  
- Use American English, active voice, and short sections that product-security and risk readers can scan.

## Review path

1. Issue (optional but preferred for material changes)  
2. Pull request against `main`  
3. Editor review (Bill Deihl)  

Large restructures should wait for an issue agreement first.
